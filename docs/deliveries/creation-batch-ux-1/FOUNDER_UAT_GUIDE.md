## 操作检查

| 旅程 | 操作与预期 |
|---|---|
| 从客户开始 | 从列表“开始创作”或详情进入独立配置；自动带入客户及适用出镜人，不重新输入已有事实。可创作条件尚未成立时，原阻断入口仍保留。 |
| 阶段一/二 | 阶段一默认 Novel10＋Persona5＋Story5＝20；阶段二默认 Novel10＋Persona15＋Story15＝40；Repurpose/Conversion均0。可修改实际数量及合计目标，合计校验后仍须 Native 资格预检；默认数量不代表有足量来源。旧草稿按原值恢复，不静默改写；明确切换阶段才应用默认值。 |
| 稳定期 | 初始1个四天周期，必须明确确认1～5个有限周期；每周期 News1/Persona3/Story2/Conversion2。不创建无限计划。 |
| 自由组合 | 各类型可为0，总0不能开始；最多40项是已批准隔离策略，不是并发40调用。目标时长仅建议。 |
| Repurpose | 单独启用、选择准确且不同的合法历史来源，数量与来源一一对应；1个原生 Request 对应1视频，4～8段不是4～8视频。不为凑量自动替换 Novel。 |
| 配置保存 | 保存/重新登录查回；修改任何来源、数量或身份后旧预检失效。旧确认不可用时可明确新建配置，不能冒用旧批准。 |
| 生成与恢复 | 检查稳定Slot和原生Request对应、逐次派发、失败及缺口分别显示；模型结果未知不自动重发。找回原任务或原已提交命令继续，不能新建伪成功结果。 |
| 内容审核 | 生成完成不等于批准。逐条阅读并作明确决定，无默认全选；集中操作委托原人审。Mix支持原生部分通过/拒绝；News段落修订及不通过仍走原生编辑，不能制造整视频负向Approval。 |
| 发布确认 | 内容批准后，独立核对标题、正文、话题及准确版本再确认；修改稿件使旧确认/旧父交付失去当前适用性，历史文件仍保留。 |
| 分类交付 | 只汇总合法已批内容和当前已确认发布版本；News一份、Mix一份，零类型不产空文件。核对Excel逐行来源/Style/数量、模板及下载SHA；不是复制拼接旧Excel。 |
| 部分结束 | 明确结束停止未派发工作；已有合法成果仍可按原Gate审核/交付。保留在途、未知和目标差额，部分结束不能标为整批完成，也不静默补量或制造事实。 |
| 历史和重放 | 重登从“我的创作批次”找回原批次，原内容/发布核对命令保持原决定；重复下载/完成导出不新建Task/Receipt/Closure/Ledger。 |
| 数据隔离 | 另一账号/Business不能读取、审批、替换来源或下载本批结果。资格撤回后的Native内容及写入仍阻断。 |
